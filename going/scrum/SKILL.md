这是一个基于 scrum 开发流程的技能. 完整开发步骤: 根据用户的需求 -> 创建用户故事 -> 产品经理生成 PRD -> 构建多组原型参考 -> 生成技术方案 -> 执行单元测试 / UI 测试 / 基准测试.

严格执行 Backpressure 机制, 我只在最后阶段进行审查.

> 在系统工程中，Backpressure 是一种下游组件向上游组件发出信号、表明无法继续接收更多工作的机制，迫使生产者放慢速度、缓冲或丢弃负载。

scrum 流程中, 就是**停止**让我成为循环中的默认反压机制.

（2）我提出需求, 使用 grill-me 进行持续追问(站在产品用户的角度)，扩展理解，达成共识. 这一阶段,应该输出用户故事 or 讨论文档.

（3）生成技术方案
